# 第一阶段开号包

这份文档用于你第一阶段直接开号。  
目标是先稳定 3 个账号：

1. 手蓝数据笔记
2. 手蓝机器人笔记
3. 手蓝储能笔记

这 3 个号足够形成一个清晰的内容矩阵，同时不会让自动发布链路一开始过于复杂。

## 一、账号一：手蓝数据笔记

### 账号名称

```text
手蓝数据笔记
```

### 简介推荐

版本 A：

```text
聚焦机器人、新能源、储能与智能装备，用数据看产业趋势，用产业链看增长兑现。
```

版本 B：

```text
关注科技制造赛道，用数据拆解热点，用产业链判断趋势与增长兑现。
```

推荐使用：版本 A

### 头像方向

- 母品牌主号
- 强调“数据、趋势、专业感”
- 不强调某单一行业

### 头像最终提示词

```text
设计一个中文科技产业数据账号头像，方形构图，深蓝与冷灰配色，极简、专业、科技感强。
中心图形为抽象数据面板与几何字母 SL 的结合，带有细微发光边缘和简洁网格感。
整体像高端产业研究品牌标识，简洁、理性、可信。
不要人物，不要复杂插画，不要大段文字，不要照片感，不要杂乱背景。
适合今日头条科技产业数据类账号头像，缩小后依然清晰。
```

## 四、建议的开号顺序

推荐顺序：

1. 手蓝数据笔记
2. 手蓝机器人笔记
3. 手蓝储能笔记

理由：

- 主账号先承接品牌
- 机器人号最贴近你当前内容优势
- 储能号与机器人号区隔明显

## 五、开号完成后你下一步要做什么

开号完成后，按这个顺序通知我：

1. 哪个账号已经注册好
2. 哪个账号头像已经上传好
3. 哪个账号准备好做头条登录认证

然后我会带你逐个执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\init_publish_login.ps1 -AccountKey default
powershell -ExecutionPolicy Bypass -File .\scripts\init_publish_login.ps1 -AccountKey robot_notes
powershell -ExecutionPolicy Bypass -File .\scripts\init_publish_login.ps1 -AccountKey energy_notes
```
