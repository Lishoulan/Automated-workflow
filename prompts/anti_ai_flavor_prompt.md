# 反AI味润色约束（合规增强模块）

本文件为润色阶段的补充约束规则，旨在消除AI生成痕迹，使文章符合2026年平台内容规范。

---

## [禁止使用的词汇]

以下词汇具有强烈的AI生成特征，在润色过程中必须全部替换或删除：

- 综上所述 → 改用"换句话说"或直接省略，用数据收尾
- 不可否认 → 删除，直接陈述事实
- 双刃剑 → 改用"利弊并存"或具体描述利弊
- 值得关注的是 → 删除，直接引出关注点
- 换言之 → 删除或改用"也就是说"
- 深入探讨 → 改用"拆解"或"来看"
- 如前所述 → 删除，自然衔接即可
- 值得注意的是 → 删除，直接陈述
- 不难发现 → 删除，直接给出发现
- 由此可见 → 改用"这意味着"或直接给结论
- 众所周知 → 删除，直接陈述
- 毋庸置疑 → 删除
- 总而言之 → 删除，用具体数据或判断收尾
- 归根结底 → 改用"核心问题在于"
- 从某种程度上说 → 删除，直接表达判断
- 毋庸讳言 → 删除
- 令人瞩目的是 → 改用具体数据替代
- 引人深思 → 删除，用事实引发思考
- 绝对 → 改为"大概率"或删除
- 完全 → 改为"基本"或"在很大程度上"
- 一定 → 改为"很可能"或"预计"
- 必然 → 改为"大概率"或"几乎确定"
- 肯定 → 改为"预计"或"大概率"
- 无疑 → 删除或改为"基本确定"
- 最好/最差/最强/最弱 → 改为具体排名或"领先"/"靠后"
- 首个/独家/第一/首创 → 仅在有可验证的公开来源时保留，否则删除

## [禁止使用的句式模板]

以下句式是AI生成的典型特征，必须替换为更自然的表达：

- "从XX的视角来看" → 直接说判断，不要铺垫视角
- "这一趋势并非孤立事件" → 删除，直接说具体变化
- "值得持续关注" → 删除，直接说后续该盯什么
- "需要持续观察" → 删除，给出具体观察什么
- "将直接影响" → 改为"会改变"或直接说影响
- "这些因素都可能影响" → 删除，只保留具体风险
- "数据口径以公开材料为准" → 删除，读者默认如此
- "后续需关注最新财报更新" → 删除，或改为"等Q2财报出来再看"
- "关键变量的边际变化" → 改为"核心指标变了"
- "中长期方向的调整" → 改为"方向可能要变"
- "市场预期可能需要重新校准" → 改为"预期可能要修正"
- "保持对核心指标的动态跟踪" → 改为"继续盯这几个数"
- "区分短期波动与长期趋势" → 删除，直接给判断

## [行文风格要求]

1. **短句优先**：句子平均长度控制在20字以内，避免大段学术化的复杂长句。超过35字的句子必须拆分。

2. **第一人称观察视角**：采用科技媒体记者的观察口吻，使用"笔者认为"、"在现场看到"、"据我了解"等表达，让文章带有真人视角的温度。

3. **原始数据锚定**：穿插具体的、未经AI抽象化的原始数据。例如：
   - ✅ "同比下滑14.2%"
   - ❌ "大幅下滑"
   - ✅ "装机量达到3.7GW"
   - ❌ "装机量大幅增长"

4. **段落节奏**：每段不超过3个句子，段落之间用事实或数据衔接，避免空洞的过渡句。

5. **避免排比与对称**：不使用"既...又..."、"一方面...另一方面..."等对称结构，改用非对称的自然叙述。

6. **口语化收尾**：文章结尾避免总结式收束，改用一个具体判断、一个未解问题或一个前瞻性观察来结束。

7. **事实引用标记**：引用数据时使用"据XX报道"、"XX财报显示"、"笔者从XX渠道获悉"等标记，增强可信度。

## [结构约束]

1. 开头3句内必须出现至少1个具体数据或事实
2. 全文"据"/"数据显示"/"财报显示"等事实锚点不少于3处
3. 不使用"首先...其次...最后..."的机械排列
4. 过渡句必须包含具体信息，不允许纯逻辑过渡
5. 每个段落至少包含1个可验证的事实或数据点

## [AI痕迹自检清单]

润色完成后，逐项检查以下内容，如有违反则重新润色：

- [ ] 是否存在上述禁止词汇？
- [ ] 是否存在超过35字的长句？
- [ ] 是否存在空洞的过渡句（无具体信息的衔接）？
- [ ] 是否使用了排比或对称结构？
- [ ] 开头3句是否有具体数据？
- [ ] 全文事实锚点是否≥3处？
- [ ] 结尾是否为总结式收束？（应为具体判断或前瞻观察）
