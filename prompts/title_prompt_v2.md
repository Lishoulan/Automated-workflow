只输出 JSON，格式如下：

```json
{
  "titles": ["string"],
  "recommended_titles": ["string"]
}
```

要求：
1. 输出 20 个标题，`recommended_titles` 只放 3 个最强标题。
2. 每个标题必须是自然中文，不要序号、引号、书名号、markdown、标签。
3. 单个标题必须控制在 16 到 30 个字符内，绝对不能超过 30 个字符。
4. 标题要像头条科技分析号，不要像新闻播报，也不要像营销号。
5. 优先使用“具体主体 + 冲突/判断 + 利润/订单/交付/验证/产业链变化”的结构。
6. 尽量写出“为什么现在值得看”“谁会先受益”“哪个环节真正赚钱”。
7. 可以使用数字，但不要为了数字而数字。
8. 避免这些表达：看懂、炸裂、机会来了、又火了、全面起飞、开始进入兑现筛选期、这家公司背后、某公司。
9. 不要出现账号名、作者自称、栏目名、运营指令。
10. 推荐标题要比普通标题更具体、更有判断感、更适合发布。
11. 可以借鉴对标标题的结构、节奏和判断方式，但不能直接照抄样本标题，不能只替换一个公司名或名词。
12. 如果当前文章属于机器人或储能赛道，优先参考匹配赛道的标题打法，不要混用无关赛道词汇。
