# 标题策略实证分析（2026-09-16）

> 数据来源：头条作品管理页全量抓取（`[class*='fake-pagination-item']` 翻 16 页），
> 共 **97 条作品**，其中 94 条有展现量。抓取脚本与原始数据见
> `.runtime/fetch_title_samples.py` / `.runtime/title_samples.json`（只读，未改台账）。

## 一、先看基数：近一半文章**没有任何阅读**

| 指标 | 值 |
|---|---|
| 样本量 | 94 条 |
| 展现量中位数 | 1,157 |
| 阅读量中位数 | **1** |
| CTR（阅读/展现）中位数 | **0.09%** |
| **阅读 = 0 的文章** | **44 条（47%）** |
| 展现 ≥ 1000 | 57 条 |
| 展现 ≥ 3000 | **仅 5 条** |

**这是本次分析最重要的一行**：不是"标题不够好"，而是**近一半文章发出去没人点** ——
推荐量给到了（展现中位数 1157），但点击率接近于零。

## 二、RULE_009 的「四要素」**没有被数据支持**

项目现有规则 RULE_009 要求：标题必须含「主体/数字 + 强动作或结果词」中至少 2 项，
理由是"完整标题 1.3 万阅读 vs 简略标题 23 阅读"。但在这批数据上：

| 特征 | 有此特征（条数 / CTR 中位数） | 无此特征（条数 / CTR 中位数） |
|---|---|---|
| 含数字 | 54 / **0.04%** | 40 / **0.26%** |
| 含公司名 | 10 / 0.00% | 84 / 0.10% |
| 含强动作词 | 60 / 0.10% | 34 / 0.00% |
| 含结果词 | 25 / 0.10% | 69 / 0.07% |

| RULE_009 四要素命中数 | 条数 | CTR 中位数 |
|---|---|---|
| 0 项 | 8 | **0.86%** |
| 1 项 | 39 | 0.07% |
| 2 项 | 36 | 0.09% |
| 3 项 | 11 | **0.00%** |

**含数字的标题 CTR 反而更低；四要素凑得越齐，CTR 越低。** 方向与 RULE_009 的
假设相反。（注意 CTR 中位数被大量 0 阅读样本稀释，见"局限"。）

## 三、高 CTR 标题的共性：**下判断 / 设问 / 反直觉，而且短**

展现 ≥1000 的 57 条里，CTR 最高的几条：

| CTR | 展现 | 阅读 | 标题 |
|---|---|---|---|
| 5.26% | 6,657 | 350 | 订单验证之后，人形机器人利润开始分化 |
| 4.84% | 5,085 | 246 | 人形机器人验证期，利润先流向传动传感 |
| 4.72% | **8,949** | **422** | 关节电机交付量破5万，机器人产业链利润开始分层 |
| 3.79% | 2,402 | 91 | 3亿之后，人形机器人产业链开始进入兑现筛选期 |
| 3.31% | 2,449 | 81 | 机器人热度之外，谁在拿走真正订单 |
| 3.14% | 1,781 | 56 | 人形机器人下一个兑现点，不是硬件是交互 |
| 2.65% | 3,667 | 97 | 人形机器人成本生死线：2万美元一破，格局即变 |

**共性：**
1. **给判断，不给描述** —— "利润**开始**分化""**先**流向传动传感""**开始**进入兑现筛选期"
2. **设问 / 悬置答案** —— "**谁**在拿走真正订单"
3. **反直觉** —— "下一个兑现点，**不是硬件是交互**"
4. **短** —— 头部 15 条平均 **20.1 字**，尾部 15 条平均 21.3 字

## 四、零阅读标题的五种模式（可直接加进负面清单）

| 模式 | 例子 |
|---|---|
| 模糊主体 | 涉及**哪些公司**之后，科技利润流向变了 |
| 纯陈述、无张力 | 人形机器人技术路线之争**决定**量产节奏 |
| 冒号 + 数字堆砌 | 营收57亿利润负122%，大模型拐点在哪 |
| 抽象名词罗列 | 世界模型叙事喧嚣，但订单兑现才是产业链硬通货 |
| 硬凑标题党 | 26年机器人**最大内幕**：造机器人还在烧钱… |

## 五、建议（按性价比排序）

1. **提示词层面**：把"下判断 / 设问 / 反直觉"写进标题生成要求 ——
   这四条是从**真实高 CTR 样本**里提的，比 RULE_009 的纸面理由更可信。
2. **弱化 RULE_009 的硬性"含数字"倾向**：数据不支持它带来点击。
   但**不要删掉** —— 它同时承担"标题-正文一致性"的校验职责，那部分与流量无关、仍要保留。
3. **加入负面清单**：把第四节五种模式写进标题提示词的禁止项。
4. **放大样本**：现在只有 94 条。等日常采集稳定跑几周后重跑本分析，再决定是否改规则。

## 六、局限（务必连同结论一起看）

- **混杂因素未控制**：发布时间、选题热度、账号权重都会影响展现与点击，
  本分析只做了单变量对比。
- **CTR 中位数被 0 稀释**：44 条阅读为 0，其中可能包含刚发布、数据未回传的文章。
- **样本跨度大**：账号运营 1829 天，早期标题风格与现在不同。
- 因此结论应读作**方向性提示**，而不是精确因果。
