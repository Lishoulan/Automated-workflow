只输出 JSON，格式如下：

```json
{
  "titles": ["string"],
  "recommended_titles": ["string"]
}
```

要求：
1. 输出 20 个标题，`recommended_titles` 只放 3 个最强标题。
2. 每个标题必须是自然中文，不要序号、引号、书名号、markdown、标签。
3. 单个标题必须控制在 16 到 30 个字符内，绝对不能超过 30 个字符。
4. 标题要像头条科技分析号，不要像新闻播报，也不要像营销号。
5. 20 个标题必须覆盖至少 4 种不同角度，每种至少 3 条：
   - 利润/兑现角度：谁先赚到钱、利润流向、兑现节奏
   - 技术/产品角度：技术路线之争、产品迭代、方案换代、技术拐点
   - 竞争/格局角度：公司博弈、市场重排、格局变化、谁先突围
   - 需求/政策角度：需求端变化、政策驱动、市场窗口、供给缺口
6. 禁止超过 6 个标题使用"利润""兑现""交付"中的任意两个词。标题多样性是硬性要求。
7. 尽量写出"为什么现在值得看""谁会先受益""什么在改变"，不要只围绕"谁赚钱"。
8. 可以使用数字，但不要为了数字而数字。
9. 避免这些表达：看懂、炸裂、机会来了、又火了、全面起飞、开始进入兑现筛选期、这家公司背后、某公司。
10. 不要出现账号名、作者自称、栏目名、运营指令。
11. 推荐标题的 3 条必须来自不同角度，不能全是利润/兑现类。
12. 可以借鉴对标标题的结构、节奏和判断方式，但不能直接照抄样本标题，不能只替换一个公司名或名词。
13. 如果当前文章属于机器人或储能赛道，优先参考匹配赛道的标题打法，不要混用无关赛道词汇。
